# tracedresearch brand assets

The mark is a **lens over a step trace**: three committed steps (dots) joined by a path, seen through a
magnifier. It stands for what the service guarantees: every step of a research run is recorded, and you
can inspect any of them.

| File | Use |
|---|---|
| `logo.svg` / `logo-dark.svg` | Lockup (mark + wordmark) for light / dark backgrounds. README header. |
| `icon.svg` / `icon-dark.svg` | Mark alone, transparent background. |
| `favicon.svg`, `favicon-32.png` | Browser tab / docs favicon (own tile, works on light and dark tabs). |
| `favicon-16.svg`, `favicon-16.png` | Hand-hinted 16 px variant, pixel-aligned so the lens and trace stay legible. |
| `avatar.svg` → `avatar-512.png` | Square, opaque avatar. |
| `social-preview.svg` → `social-preview.png` | Repository social preview (Settings → Social preview), 1280×640, opaque. |

## Colors

| Token | Hex | Contrast | Use |
|---|---|---|---|
| Ink | `#0A1418` | 18.7:1 on `#FFFFFF` | Mark and wordmark on light backgrounds; favicon tile; social background |
| Mist | `#E8F1F2` | 16.5:1 on `#0D1117` | Mark and wordmark on dark backgrounds |
| Teal (light) | `#0B7A75` | 5.2:1 on `#FFFFFF` | Trace and "research" on light backgrounds |
| Teal (dark) | `#2DD4BF` | 10.2:1 on `#0D1117` | Trace and "research" on dark backgrounds |
| Muted | `#93A8AC` | 7.5:1 on Ink | Secondary text on the social preview |

The build script checks every pairing against GitHub's light (`#FFFFFF`) and dark (`#0D1117`)
backgrounds and fails below WCAG's 3:1 minimum for graphics. All of them also clear 4.5:1.

## Usage

- Keep clear space around the lockup of at least the lens radius.
- Below 120 px wide, use the mark alone; below 24 px, use the favicon variants.
- Do not recolor, stretch, rotate, outline, add effects, or set the wordmark in another font.
- Use the dark variants on dark backgrounds.

## Rebuilding

Every asset is generated by `tools/build_brand.py`, so it is reproducible and reviewable as code:

```sh
cargo install resvg --locked --version 0.48.1   # PNG export
uv run assets/brand/tools/build_brand.py
```

The script fetches JetBrains Mono v2.304 from its official release, verifies its SHA-256, outlines
the wordmark, checks color contrast, rejects any SVG containing scripts, event handlers,
`foreignObject` or external references, and renders the PNGs with resvg.
